# ProChange — All-in-One Developer & Utility Suite

A fast, local-first, privacy-focused developer and productivity workbench built with Next.js 16, React 19, TypeScript, Tailwind CSS 4, and Lucide icons.

## Requirements
- Node.js 20.9 or newer
- npm

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Features & Utilities
- **Converters**: Cron Parser, Timestamp & Dates, JSON <> CSV / Table, JSON <> YAML, Number Base Converter (Bin/Oct/Dec/Hex/ASCII), cURL to Fetch & Axios
- **Encoders / Decoders**: Base64 Text & Data URL, URL Encoder, HTML Entities, QR Code Generator & Scanner, JWT Claims Inspector
- **Formatters**: JSON Formatter/Minifier, SQL Beautifier, XML Formatter, CSS Unit Converter, JSON to TypeScript/C# Types, Markdown Live Preview
- **Generators**: Custom Mock Data Generator (10 to 1,000+ records in JSON/CSV/SQL), High-Entropy Password Generator, UUID v4 Generator, Lorem Ipsum & Mock Users, Cryptographic Hash Generator
- **Daily & Finance Utilities**:
  - Salary & LPA In-Hand Calculator (CTC breakdown, PF, Tax, take-home)
  - Currency & Crypto Trend Converter with interactive market charts
  - Disposable Temporary Mailbox interface with live message feed & OTP extraction
  - Ready-to-Copy Wishes & Workplace Email Message Templates Hub
  - Movie & TV Explorer
- **Testers & Text**: Regex Pattern Evaluator, Text Analyzer & Case Converter (camelCase, snake_case, etc.), JSON Diff Comparator
